 [ชื่อโปรเจค : โปรแกรมช่วยประหยัดตังค์]
> ช่วยประหยัดตังค์ผ่านการแจ้งเตือนว่าเกินงบที่จะใช้ในวันนั้นแล้วหรือยัง

📌 1. ที่มาและความสำคัญ (Introduction)
 * **ปัญหาที่พบ:** มีคนที่ใช้จ่ายแบบไม่มีวินัย หรือ อาการ "หน้ามืด" เห็นเงินเหลือ
 * **เป้าหมาย:** พัฒนาโปรเจคนี้ขึ้นมาเพื่อช่วยสำหรับผู้ใช้ที่หยุดคิดก่อนใช้จ่ายผ่านระบบล็อคงบประมาณ และแจ้งเตือนทันทีเมื่อเกินเกณฑ์

🚀 2. ความสามารถของโปรแกรม (Features)
* [ ] ฟีเจอร์ที่ 1: ระบบล็อคประมาณตั้งต้นทันทีที่เริ่มบันทึกรายการแรก เพื่อป้องกันการขยับงบเพิ่มตามใจชอบระหว่างวัน
* [ ] ฟีเจอร์ที่ 2: คำนวณยอดที่ใช้ไปแล้วและวงเงินที่เหลือทันที่ ในขณะที่กำลังพิมพ์ราคาสินค้า
* [ ] ฟีเจอร์ที่ 3: เด้ง pop - up เมื่อการใช้จ่ายมีค่ารวมสูงกว่างบที่ตั้งไว้
* [ ] ฟีเจอร์ที่ 4: มีระบบปรับโหมดมืด/สว่าง

🛠 3. เครื่องมือที่ใช้ (Tech Stack)
 * **Language:** Python
 * **Library:** Tkinter
 * **Design Tool:** Canva

💻 5. วิธีการใช้งาน (How to run)
 1. ดาวน์โหลดไฟล์ .py
 2. เปิดโปรแกรม IDLE python
 3. กด Open ที่หัวข้อ File แล้วเลือก .py ที่โหลดมา
 4. กดปุ่ม F5 หรือ กดหัวข้อ Run แล้วกด Run Module
